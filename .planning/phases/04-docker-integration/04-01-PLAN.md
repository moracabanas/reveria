  <action>
Create `frontend/Dockerfile` with multi-stage build:

1. Builder stage:
   - Base: node:20-alpine
   - Workdir: /app
   - Copy package.json and package-lock.json first (for layer caching)
   - Run npm ci to install dependencies
   - Copy remaining source files
   - Run npm run build (uses next.config.ts output: 'export')
   - Artifact: dist/ directory with static export

2. Production stage:
   - Base: nginx:alpine
   - Copy nginx.conf for serving static files
   - Copy dist/ from builder stage
   - Expose port 3000
   - Start nginx

3. Alternative standalone approach (simpler):
   - Use node:20-alpine for both stages
   - Builder stage: npm install && npm run build
   - Runtime stage: Use npx serve to serve static dist/
   - Expose port 3000

Recommended: Use the nginx approach for minimal image size (~15MB vs ~200MB).
</action>
