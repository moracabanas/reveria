<context>
@docker-compose.yml
@frontend/tests/fixtures/sample.csv

## End-to-End Flow
1. User uploads CSV via frontend (localhost:3000)
2. Frontend POSTs to backend /predict/file
3. Backend creates job, returns job_id
4. Frontend polls backend /predict/status/{job_id}
5. Backend returns COMPLETED with forecast data
6. Frontend displays D3.js chart with results

## Test Scenarios
- Upload sample.csv to frontend
- Verify job_id returned
- Poll until COMPLETED
- Verify forecast array present
- Verify metadata fields present
</context>

Run end-to-end integration tests:

1. Start services:
   ```bash
   docker compose up --build -d
   ```

2. Wait for services to be healthy:
   ```bash
   sleep 15  # Allow services to start
   ```

3. Verify backend health:
   ```bash
   curl http://localhost:8000/health
   ```

4. Verify frontend accessible:
   ```bash
   curl http://localhost:3000
   ```

5. Test prediction flow with sample CSV:
   ```bash
   # Upload file and get job_id
   JOB_RESPONSE=$(curl -X POST -F "file=@frontend/tests/fixtures/sample.csv" \
     -F "context_size=512" \
     -F "prediction_length=100" \
     http://localhost:8000/predict/file)
   JOB_ID=$(echo $JOB_RESPONSE | grep -o '"job_id":"[^"]*"' | cut -d'"' -f4)
   echo "Job ID: $JOB_ID"

   # Poll status until COMPLETED
   for i in {1..30}; do
     STATUS=$(curl -s http://localhost:8000/predict/status/$JOB_ID)
     echo "Status: $STATUS"
     if echo "$STATUS" | grep -q "COMPLETED"; then
       break
     fi
     sleep 2
   done

   # Get result
   curl -s http://localhost:8000/predict/result/$JOB_ID
   ```

6. Document results in 04-03-INTEGRATION-TEST.md
</action>
