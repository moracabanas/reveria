## Interface Contracts (this plan creates)

```python
from dataclasses import dataclass
from typing import List, Optional, Union
import numpy as np

@dataclass
class CSVParseResult:
    """Result of parsing a CSV file."""
    data: np.ndarray          # 1D array of time series values
    column_names: List[str]   # Detected or provided column names
    selected_column: str      # Name of the selected value column
    row_count: int
    detected_encoding: str
    detected_delimiter: str
    has_header: bool
    
class CSVValidationError(Exception):
    """Raised when CSV validation fails."""
    pass
```

## Discretionary Decisions (OpenCode's choice)

- **CSV library**: Use pandas (already in dependencies, familiar API, handles large files)
- **Encoding detection**: Try utf-8 → latin-1 → cp1252 fallback (simpler than chardet, no new dependency)
- **Delimiter detection**: Try [',', ';', '\t', '|'] and pick the one producing most consistent columns
- **Header detection**: Check if first row contains non-numeric values
- **Error format**: Raise CSVValidationError with descriptive messages (not RFC 7807 — that belongs in API layer)
