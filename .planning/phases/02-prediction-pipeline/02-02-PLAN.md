Purpose: Prediction with TimesFM can take seconds (especially for large context sizes). Async jobs prevent HTTP timeouts and provide a clean API for tracking progress.

Output: `backend/app/jobs.py` with in-memory job store + comprehensive test suite.

## Locked Decisions (D-04)

Per D-04 from CONTEXT.md: **Always async processing** — return job ID immediately, poll for results:
- `POST /predict/file` → returns `{ "job_id": "uuid", "status": "processing" }`
- `GET /predict/status/{job_id}` → poll for status
- `GET /predict/result/{job_id}` → get results when complete

## Discretionary Decisions (OpenCode's choice)

- **Job storage**: In-memory dict with asyncio.Lock (simplest, no new dependencies, sufficient for single-user local tool per REQUIREMENTS.md "Out of Scope")
- **Job cleanup**: No cleanup for now (single user, local deployment; memory is not a constraint)
- **Job ID**: UUID4 strings
