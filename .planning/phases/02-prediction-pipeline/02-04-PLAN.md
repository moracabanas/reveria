## Locked Decisions (MUST implement exactly)

### D-01: Separate endpoints
- `POST /predict/file` — accepts multipart/form-data with CSV file + config fields
- `POST /predict/data` — accepts JSON with raw time series array + config

### D-02: Multipart form-data for file endpoint
File + config in same request (not two-step)

### D-03: Response format
```json
{
  "forecast": [1.2, 1.3, 1.4],
  "metadata": {
    "computation_time_ms": 245,
    "model_used": "TimesFM2p5",
    "input_points": 1024,
    "prediction_length": 96
  }
}
```

### D-04: Always async processing
- `POST /predict/file` → returns `{ "job_id": "uuid", "status": "processing" }`
- `GET /predict/status/{job_id}` → poll for status
- `GET /predict/result/{job_id}` → get results when complete

## API Contract (this plan implements)

### POST /predict/file
Request: multipart/form-data
- `file`: CSV file (required)
- `context_size`: integer, default 512
- `prediction_length`: integer, default 96
- `frequency`: string, default "auto"
- `column_index`: integer, optional (0-based column selection)
- `column_name`: string, optional (column name selection)

Response (200 OK):
```json
{
  "job_id": "uuid-string",
  "status": "processing"
}
```

### POST /predict/data
Request: JSON body
```json
{
  "data": [1.0, 2.0, 3.0, ...],
  "context_size": 512,
  "prediction_length": 96,
  "frequency": "auto"
}
```

Response (200 OK):
```json
{
  "job_id": "uuid-string",
  "status": "processing"
}
```

### GET /predict/status/{job_id}
Response (200 OK):
```json
{
  "job_id": "uuid-string",
  "status": "processing",
  "created_at": "2024-01-01T00:00:00Z",
  "updated_at": "2024-01-01T00:00:05Z"
}
```

### GET /predict/result/{job_id}
Response (200 OK, when completed):
```json
{
  "job_id": "uuid-string",
  "status": "completed",
  "forecast": [1.2, 1.3, 1.4],
  "metadata": {
    "computation_time_ms": 245,
    "model_used": "TimesFM2p5",
    "input_points": 1024,
    "prediction_length": 96
  }
}
```

Response (202 Accepted, when still processing):
```json
{
  "job_id": "uuid-string",
  "status": "processing"
}
```

       ```python
       async def _run_prediction_task(
           job_id: str,
           data: np.ndarray,
           config: PredictionConfig,
           model: ForecastingModel
       ):
           try:
               await update_job_status(job_id, JobStatus.PROCESSING)
               result = await run_prediction(data, config, model)
               await update_job_status(
                   job_id, JobStatus.COMPLETED,
                   result={
                       "forecast": result.forecast.tolist(),
                       "metadata": result.metadata
                   }
               )
           except Exception as e:
               logger.error(f"Prediction failed for job {job_id}: {e}")
               await update_job_status(
                   job_id, JobStatus.FAILED,
                   error_message=str(e)
               )
       ```

    4. **Router endpoints**:
       - `POST /file` (multipart):

         - Parse CSV: `parse_csv(content, column_index, column_name)`
         - Create config: `PredictionConfig(...)`
         - Create job: `job = create_job(config=as_dict)`

         - Return `JobResponse(job_id=job.job_id, status="processing")`
