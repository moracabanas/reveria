## Discretionary Decisions (OpenCode's choice)

- **Normalization method**: Min-max scaling to [0,1] (requirement MODEL-04 specifies [0,1])
  - Store min/max values for denormalization
  - Handle edge case: all values identical (set range=1 to avoid div by zero)
- **Frequency**: Store as string ("D", "H", "M", etc.) — pass through to metadata, actual resampling is v2 scope
- **Context size**: Maps to `input_chunk_length` parameter of ForecastingModel
- **Prediction length**: Maps to `n` parameter of `predict()` method

       @dataclass
       class PredictionConfig:
           context_size: int = 512      # Must be >= 32, <= 50000
           prediction_length: int = 96  # Must be >= 1, <= 1000
           frequency: str = "auto"      # Passed through to metadata
           
           def __post_init__(self):
               if self.context_size < 32:
                   raise ValueError("context_size must be at least 32")
               if self.prediction_length < 1:
                   raise ValueError("prediction_length must be at least 1")

    2. **`Normalization` class** (internal):
       - `normalize(data: np.ndarray) -> Tuple[np.ndarray, dict]`:
         - Compute min and max of data
         - If max == min: set range=1.0 to avoid division by zero
         - Scale: `(data - min) / range`
         - Return normalized array + `{"min": float, "max": float, "range": float}`
       - `denormalize(normalized: np.ndarray, params: dict) -> np.ndarray`:
         - Reverse: `normalized * range + min`
         - Return denormalized array

    3. **`PredictionResult` dataclass**:
       ```python
       @dataclass
       class PredictionResult:
           forecast: np.ndarray
           metadata: dict  # Contains: computation_time_ms, model_used, input_points, prediction_length, config_used
       ```

    4. **`PredictionService` class**:
       - `__init__(model: ForecastingModel)` — accepts the loaded model instance
       - `async def run_prediction(data: np.ndarray, config: PredictionConfig) -> PredictionResult`:
         - Record start time
         - Slice data to last `config.context_size` points (or use all if shorter)
         - Normalize sliced data
         - Call `self.model.fit(normalized_data)`
         - Call `self.model.predict(n=config.prediction_length)`
         - Extract forecast array from result dict
         - Denormalize forecast
         - Compute elapsed time
         - Return PredictionResult with forecast + metadata dict:
           ```python
           metadata = {
               "computation_time_ms": int(elapsed * 1000),
               "model_used": "TimesFM2p5",
               "input_points": len(sliced_data),
               "prediction_length": config.prediction_length,
               "context_size": config.context_size,
               "frequency": config.frequency,
           }
           ```

    5. **Module-level convenience function**:
       - `async def run_prediction(data: np.ndarray, config: PredictionConfig, model: ForecastingModel) -> PredictionResult`:
         - Creates PredictionService and calls run_prediction

    - Must handle the case where model is None (not loaded) — raise RuntimeError
    - Must be async since model.fit/predict may block
    - Normalization must be exact: denormalize(normalize(x)) ≈ x (within float tolerance)
